SQL Server, niveau 2 : les raccourcis de SSMS.

F5 exécute. Ctrl+R cache la grille (encore Ctrl+R : elle revient). Maj+↓ puis F5 : seulement la sélection, le geste le plus utile. Ctrl+K puis Ctrl+C commente la ligne, Ctrl+K puis Ctrl+U enlève le commentaire. Ctrl+Maj+L / Ctrl+Maj+U : minuscules, MAJUSCULES. Ctrl+Maj+Q ouvre le concepteur de requêtes. Alt+F1 sur le nom d’une table : colonnes, index, contraintes. Ctrl+Maj+M remplit le modèle. F4 ouvre la fenêtre Propriétés. Ctrl+L affiche le plan estimé, sans exécuter la requête.

Le piège : rien de sélectionné, F5 lance toute la fenêtre, y compris le DELETE oublié en haut. On sélectionne, puis on exécute.
